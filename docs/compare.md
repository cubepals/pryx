# Capability comparison

Public documentation reviewed on **2026-11-08**. “Not found” means the cited documentation
was checked and did not establish that capability; it does not claim the product cannot do it.
Hosted service plans, regions and guarantees can differ. Links describe behavior, not equivalent
isolation or performance. pryx's local tools require the prepared images and the host policy
in [native tools](native-tools.md); [tiers](tiers.md) states their limits.

pryx is **source available under FSL**, not currently OSI open source. Each release converts
to Apache-2.0 after two years. A feature count cannot substantiate an unqualified “most
comprehensive open-source” claim. This table makes the narrower capability comparison auditable.

Every pryx implementation is exercised by the existing unit, Docker or end-to-end CI suites;
measurements are in [speed](speed.md). Competitor citations are dated in each cell and describe
the published SDK documentation, not a live paid-account test. E2B's complete docs were read from
its docs export, Daytona's from its official documentation export, and Cloudflare's from its
sandbox documentation export. No competitor code was copied.
