# K5 validation

Built the generic edge service and authenticated control protocol: incremental route polling and
acknowledgments, TLS SNI/HTTP Host/raw port fronts, bounded silent holds, shared wakes, stable
public assignments, session/idle/visit reporting, per-address/per-destination admission, metrics
and stale-epoch connection closure. The edge OpenAPI document and generated types are committed.
The node protocol and original format fixtures remain unchanged.

The full workspace check passed 213 tests across 32 files against real local Postgres, with
6812 assertions and no skips/failures. This includes real local TLS with a test CA, HTTP body
replay after a hold, shared wakes after one client cancels, continued raw traffic beyond the
hold deadline, stale closes, route acknowledgment barriers, port quarantine and source limit/poll
property tests. Biome, TypeScript, OpenAPI/SDK drift, frozen install, expanded structure,
actionlint and edge binary compilation passed.

Silent-listener measurements ran for curl, Node fetch, Python requests, Go net/http, Chromium
and OpenSSH, three samples per applicable protocol. docs/edge.md includes commands, versions,
p50/p90, censoring and the chosen five-second default. Safari was unavailable on Linux (n=0).
The initial missing-library diagnostic is kept separate from the successful final samples.

The new real daemon HTTP/HTTPS sleep/wake suite, TLS image fixture and epoch-close scenario are
configured in CI. Docker-backed e2e was not run locally; no remote CI result is claimed.
