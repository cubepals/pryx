Local verification: locked Rust build and 355 tests pass, with 12 existing root/Docker cases
assigned to CI and one opt-in storage benchmark excluded from that ordinary test command; format, both clippy modes, deny and Rust structure pass. All 290 Bun tests and
7,290 assertions pass against real Postgres, with TypeScript structure, frozen dependency
installation, workflow lint, compiled release artifacts and image entrypoint checked. Python
client generation, eight local unit cases and wheel/source distribution builds pass. Its real
control cases run in CI. REUSE and documentation consistency pass.

[Speed measurements](../speed.md) retain before/after n=30 cohorts, exact sources, host
metadata and every raw sample. The final frozen K9 cohort meets its three specified p50 budgets:
public exec 47.50 ms, template create 186.38 ms and suspended wake 27.28 ms. Its exec p90 is
52.39 ms, which is not a specified K9 threshold; the earlier failed 57.36 ms median is retained.
The current K11 agent path has p90 run 2.04 ms, first byte 2.06 ms and expose/200 4.17 ms,
passing the 20/10/200 ms thresholds. The final K12 process cohort has p90 run 2.50 ms, first
byte 2.54 ms, expose/200 47.74 ms and image startup 6,507.19 ms; all four budgets pass.
K10 admission timing and K13 native costs are measured without invented numeric thresholds.
The final native celld repeat records local/native backend-start p90 172/259 ms and warm HTTP
p90 5.12/5.06 ms. Its lower start-through-first-response includes owner readiness and polling;
it is not attributed to an isolated transport optimization. Historical cohorts remain available. Raw output belongs to the cited CI artifacts; the repository keeps only its summary.

Unavailable checks: no physical 16 GiB host, actual laptop or hosted-platform account was
available. The observed runner is 8 GiB-class; the report does not invent 16 GiB measurements
or simultaneous capacity for 50 sandboxes. Compose is exercised in CI with the just-built image;
the identical Docker build context is built separately. Live cloud-provider tests have no
credentials. Sandbox Docker/root and end-to-end suites did not run locally; they run in CI.
The managed local kernel's mandatory Landlock fail-closed case was tested.

The process tier shares its enclosing kernel/network and samples memory rather than imposing
a cgroup hard cap; shared UID mode requires mutually trusted workloads. Native celld currently
supports the single-node dev store and refuses distributed ownership until remote fencing is
proven. The unchanged-release Docker socket experiment explicitly fails unsupported image-build
operations and remains unshipped. Upstream patches were prepared and tested, with no submission.
