## Limits of verification

The managed local kernel refuses the native process tier's mandatory Landlock/network policy;
the runtime remains fail-closed. Local external VM HTTP also fails while the host's configured
proxy works. Neither condition is bypassed. Root/Docker suites, native process acceptance,
real package downloads and full release comparisons are CI-owned checks.

No physical laptop/host or hosted-platform account was available. Live provider credentials
remain unavailable. This milestone adds no provider skip and makes no claim about a live
provider run. The observed CI memory and CPU metadata, rather than an invented machine size,
accompany each measurement report.

Wasm has a shared sidecar fault domain and virtual heap/process bounds, without a per-VM CPU
rate quota. Sleep retains files and recreates compute; processes and terminals do not survive.
The pinned upstream interface supports HTTP application ingress, without UDP, raw TCP, TLS
passthrough or application WebSockets. The agent's own authenticated terminal WebSocket works.
The process tier's shared-UID mode remains a weaker boundary for mutually trusted workloads.
These limitations and the differences in resource enforcement are documented explicitly.
