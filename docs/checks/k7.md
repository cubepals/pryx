# K7 validation

Built direct Hetzner, Boat, strict SSH/manual and fake providers; durable keyed acquisition,
hash-only derived enrollment, operator/CLI verbs, conservative autoscaling and safe release.
Provider/OpenAPI provenance and zero-sample measurement tables are in docs/providers.md.

Ran locally against real Postgres:

- Final `bun run check`: 235 passed, zero failed, 6,906 assertions across 37 files (83.49 seconds).
  Lint, TypeScript, all generated API drift, documentation and release metadata checks ran in it.
- `bun install --frozen-lockfile`, compiled CLI/control/edge and SDK ESM release build.
- Expanded structure check, actionlint and git diff whitespace check.
- Node OpenAPI and original format tests/fixtures have no diff; Cubepals checkout has no diff.

Earlier final runs failed: a 20 MiB multipart retry exceeded five seconds and contaminated two
following fixture assertions; after a per-copy budget adjustment, a public-create/Postgres test
also exceeded five seconds. The workspace test command now defaults to 30 seconds, preserving
explicit deadlines and production policy. Only the clean final run is counted above.

Not run locally: Docker-backed/control e2e, live Hetzner provisioning, Boat runtime/private network
probe, manual SSH enrollment, Fly Docker probe, or remote CI. No provider credentials/SSH host were
supplied. The Hetzner CI step visibly skips without PRYX_HETZNER_TOKEN; with it, the test creates
and cleans temporary resources and exercises CLI acquire/release plus a real sandbox. It can add
up to 20 minutes to CI when enabled. No live join percentile or remote success is claimed.
