# K8 validation

Built the optional RivetKit actor, sandbox-agent/agentOS providers, coding-agent example,
celld backend proposal and Worker/DO bridge prototype. Pinned interface evidence is in
integrations/interfaces.md. Core runtime packages do not import either integration.

Built the disabled-by-default store-lease feature, conditional S3 authority, session-bound
grants, independent cgroup watchdog, expired-generation CAS proofs and snapshot recovery.
Source copies remain retained and block rental release until a fresh inventory from the
recorded private host confirms removal. Host policy is latched against accidental downgrade.
Host assumptions, operational limits and zero-sample local measurement tables are in
docs/store-lease.md; the request-count model is explicitly not a measurement.

The final full workspace check passed 244 tests across 40 files against real Postgres,
with 6,951 assertions and no failures (62.15 seconds). Biome, TypeScript, generated node/public/
edge contract drift, API documentation and release metadata checks ran in that command.
The Rivet package built and packed its ESM entries, source and runnable examples.

After the pure function extractions, `cargo test --locked` passed 312 tests with zero
failures and 13 Docker/root tests ignored. `cargo fmt --check`, all-targets and production
clippy with warnings denied, `cargo deny --locked check`, frozen Bun install, generated
contract/docs/release drift, both expanded structure checks and actionlint passed. The
structure baseline, original formats/fixtures, AGENTS.md, PLAN.md and Cubepals checkout
remain unchanged.
The final `cargo build --locked` passed; its debug binary reports pryxd 0.1.0.

Release-profile signature tests actually ran: five passed, including refusal of the old
statement. A built release binary copied to the former fixture name still printed pryxd
0.1.0. Debug-only fixture name/layout/test-key compatibility is covered separately; it does
not widen production release trust. These release tests/build preceded the final session/
policy-latch changes; the final production configuration is also checked by clippy.

Earlier runs are not counted as passes: a Rust schema comment drift needed regeneration;
the policy latch initially lacked an explicit durable-write error conversion; the stricter
structure check required pure function extractions; and a Bun
diagnostic without DATABASE_URL skipped database tests. The full Postgres result above is
the accepted workspace run.

Not run locally: Docker-backed daemon tests, upstream Cubepals contract, Rivet/agentOS/celld
real-daemon integration tests, store-cut/SIGSTOP/recovery fault tests, fresh systemd installer,
live provider provisioning, or live model calls. The workflow includes those Docker/e2e
checks, root execution for the two-node suite, and raw lease measurement collectors. Its
combined integration job has a 90-minute ceiling; optional Hetzner work visibly skips without
credentials. No remote result is inferred from local compilation or workflow lint.
